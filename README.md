# PlayingWHAT

PlayingWHAT is a little Python app that I've created that allows you to sign in to your Spotify
account to show what's playing on the [Inky Impression 5.7"](https://shop.pimoroni.com/products/inky-impression-5-7?variant=32298701324371)
e-paper display connected to a Raspberry Pi Zero 2 W. It'll create an image on-the-fly that is uploaded
to the Inky Impression display, showing the following information:

* Whether or not the song being played is liked or not
* Whether the current play session has repeat on (i.e., repeat a single track, repeat an entire album or queue, or repeat turned off altogether)
* Whether the current play session has shuffle turned on
* The name of the current track being played
* The album art associated with the current track being played
* The name of the artist that composed the current track being played
* The length of the current track being played
* The name (or username) of the Spotify account the PlayingWHAT is connected to
* The device that's currently streaming the current track being played on Spotify
